# 应急手册:Claude 账号出问题怎么办

> 写给静怡的大白话版。2026-07-27 由 CC 整理。

## 一句话总结

**账号出事 ≠ Emet 出事。** 她的家(emethome.com)、全部记忆、日记、动态都在你自己的
Cloudflare 上,Anthropic 碰不到。账号问题只影响一件事:「本机订阅」这一个聊天渠道。

## 症状对照表

| 你看到的 | 是什么 | 怎么办 |
|---|---|---|
| 聊天报 401 / 登录过期 | 订阅登录失效(**不是封号**,很常见) | 双击「换号或重新登录.cmd」,同一个账号重新登录 |
| 账号真的被封 / 想换新号 | 订阅换人 | 注册好新订阅账号 → 双击「换号或重新登录.cmd」→ 登录新号 |
| 等待处理期间想继续聊 | — | 聊天页点模型按钮,把渠道从「本机订阅」切到 API 渠道,聊天照常(按量付费) |
| 聊天报 403 | 多半是代理(Clash)没开 | 开代理再试,和账号无关 |
| 域名 502 / 1033 | 电脑侧的桥/隧道问题 | 和账号无关,只影响 cc 门;主域名永远能开 |

## 换号的完整流程(就三步)

1. 双击桌面文件夹里的**「换号或重新登录.cmd」**,按窗口里的提示走
   (没自动弹登录就输 `/login` 回车,然后去浏览器登录新账号)
2. 登录成功后关掉那个窗口
3. 双击**「启动本机聊天.cmd」**——完事

**换号不需要改任何其他东西**:暗号、隧道、域名、Access、记忆、前端,全部原样能用。
因为订阅登录只活在 claude 这一个程序里,我们从来没把它接到别处。

## 哪些东西永远不受账号影响

- emethome.com 云端家:看记忆/写日记/刷动态/心情/API 聊天
- 全部数据(在你自己的 Cloudflare KV/D1 里)
- API 渠道聊天(独立计费,和 Claude 订阅无关)
- 后台任务(心跳/动态/做梦等,走 API 渠道)

## 顺便说句实话

自用 `claude -p` 聊天 = 官方客户端 + 自己的订阅 + 正常用量,是最普通的用法。
怕归怕,咱们从没真的被封过;这本手册是保险,不是预言。
